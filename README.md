Amazon Shopping Website – Front Page Clone

About the Project

A front-page clone inspired by Amazon, developed using HTML, CSS, and Bootstrap. The project recreates the layout and design of an online shopping website.

Technologies Used
- HTML5
- CSS3
- Bootstrap

Features
- Navigation bar and search section
- Product categories and shopping sections
- Promotional banners
- Structured and user-friendly interface

How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
